# Dust765.4 Launcher

Official launcher for Dust to run the game client.

![image](dust765.4_launcher.png)

## Installation

Download the [latest release](https://github.com/bittiez/TUO-Launcher/releases), unzip the file and run `Dust765.4 Launcher.exe`.
